# Musique

Music player with hand drawn pixel art.

## Features
- Import songs directly from your device's local storage
- Create and manage playlists
- Shuffle playback for playlists
- Loop a single song on repeat
- Custom cover images for songs and playlists, editable anytime
- Song title and artist auto-fetched from the MP3's metadata, editable anytime

## Build
1. Clone the repo
2. Open the project folder in Android Studio
3. Let Gradle sync
4. Click Run (or build a signed APK — see Releases for a pre-built version)

Requires Android 7.0 (API 24) or higher.
